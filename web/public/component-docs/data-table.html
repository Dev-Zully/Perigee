    DataTable — reusable table component with sorting, client-side filtering, and pagination. (WEB-33)

    Import

    import { DataTable } from '@/components/ui/DataTable';

    Props

    PropTypeDefaultRequiredDescription
    columnsColumnDef<T>[]—YesColumn definitions.
    dataT[]—YesRow data.
    rowKey(row: T, index: number) => string | number—NoOptional row key extractor. Defaults to the row index. Providing a stable key (e.g. a unique id field) avoids reconciliation issues when sorting / filtering.
    pageSizenumber0NoNumber of rows per page. Pass 0 or undefined to disable pagination.
    filterKeys(keyof T | string)[]—NoKeys of columns searched by the filter input. When omitted, all string/number cell values are included in the search.
    filterPlaceholderstring'Filter…'NoPlaceholder text for the filter input.
    emptyMessageReact.ReactNode'No results found.'NoMessage shown when the filtered result set is empty.
    titleReact.ReactNode—NoOptional title rendered in the table header bar.
    subtitleReact.ReactNode—NoOptional subtitle rendered below the title.
    classNamestring—NoAdditional className for the outermost container.
    'data-testid'string—Nodata-testid applied to the root element (WEB-34 compatibility).

    Usage

    const columns: ColumnDef<MyRow>[] = [
  { key: 'name', header: 'Name', sortable: true },
  { key: 'value', header: 'Value', sortable: true, align: 'right' },
];
<DataTable columns={columns} data={rows} pageSize={10} />

    Accessibility

    • The filter input is labelled by a visually hidden <label> and an aria-label, so it is reachable both by visible text and by name.
    • Sortable headers are real <button> elements inside <th scope="col">, and the sorted column exposes aria-sort (ascending / descending).
    • Pagination controls carry explicit aria-labels ("First page", "Next page", …) and use disabled, so the current position is announced.
    • The empty state renders inside a single full-width cell, which keeps the table structure valid when there are no rows.
