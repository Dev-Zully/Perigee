    Badge

    Data display · Status pills, severity tags, resource budget indicators.

    Page status: stable · Tracks WEB-27 (#113), WEB-38 (#492)

    Status: stable · Since: 0.1.0 · Source: components/ui/Badge.tsx:49

    Standardized Badge / pill component.

    Resolves WEB-27 (#113): component library not standardized. Use for status labels, resource budget indicators, and severity tags.

    Import

    import { Badge } from '@/components/ui/Badge';

    Props

    PropTypeDefaultRequiredDescription
    variantBadgeVariant"default"NoSemantic colour pairing. Every variant is contrast-audited (see below).
    childrenReact.ReactNode—YesShort label text — keep it to one or two words so the pill stays compact.
    classNamestring—NoExtra Tailwind classes merged after the variant classes.

    Usage

    <Badge variant="success">Passed</Badge>
<Badge variant="danger">Over Budget</Badge>

    Accessibility

    • Colour is never the only signal: the text label carries the meaning, and every variant pairing is audited for ≥ 4.5:1 contrast on its tinted background (WEB-38 / #492).
    • The label is plain text inside a <span>, so it is read as part of the surrounding sentence — do not use it as the sole status announcement for dynamic updates; pair with LiveStatus / LiveAlert.

    Types

    BadgeVariant

    Allowed values:

    • default
    • success
    • warning
    • danger
    • info

    Migration notes

    • Ad-hoc status pills replaced by Badge — shipped in v0.0.1.
      • Badge has no size prop — density is inherited from the surrounding text.
      • Colour is never the only signal: keep a text label inside the pill (WEB-38 / #492).
