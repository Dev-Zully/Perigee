    LiveAlert

    Status: stable · Since: 0.1.0 · Source: components/LiveRegion.tsx:94

    Assertive live region for failures the user must act on.

    Import

    import { LiveAlert } from '@/components/LiveRegion';

    Props

    PropTypeDefaultRequiredDescription
    messagestring—YesThe alert message. Rendered inside the region; empty = silent.
    "data-testid"string—NoTest hook.

    Usage

    <LiveAlert message={error ? `Analysis failed: ${error}` : ''} />

    Accessibility

    • Renders role="alert" with aria-live="assertive" and aria-atomic="true", so the whole message is re-announced on every change. Reserve it for errors: assertive announcements interrupt the user.
    • Keep the component mounted and change only message; a region that mounts together with its text is frequently not announced.
