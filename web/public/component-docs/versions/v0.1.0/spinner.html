    Spinner

    Feedback · Inline and block loading states.

    Page status: stable

    Status: stable · Since: 0.1.0 · Source: components/ui/Spinner.tsx:91

    Standardised loading spinner for the Perigee component library.

    Resolves the ad-hoc loading indicator inconsistency noted across multiple components. Use this instead of inline SVGs or Lucide's Loader2 so that size, color, and motion behaviour are uniform app-wide.

    Import

    import { Spinner } from '@/components/ui/Spinner';

    Props

    PropTypeDefaultRequiredDescription
    sizeSpinnerSize"md"NoControls the outer diameter of the spinner ring. Defaults to "md".
    colorSpinnerColor"primary"NoColor token for the spinning arc. "primary" matches the Perigee brand cyan (#33C5E0). Defaults to "primary".
    labelstring—NoOptional accessible label announced by screen readers. When omitted the spinner is purely decorative (aria-hidden="true").
    classNamestring—NoExtra Tailwind classes forwarded to the root element.

    Usage

    // Decorative (no announcement)
<Spinner size="sm" color="primary" />

// Accessible (announces to screen readers)
<Spinner size="md" label="Loading vault data…" />
*   // Custom color with label below the ring
  <Spinner size="lg" color="white" label="Connecting…" />

    Accessibility

    • Without label the ring is aria-hidden="true", which is correct inside a button that already has a name ("Saving…").
    • With label the ring becomes role="status", which announces politely; for failures that must interrupt, use LiveAlert instead.
    • The CSS animation is disabled by the global prefers-reduced-motion rule, so the ring must never be the only progress signal — pair it with text.

    Types
