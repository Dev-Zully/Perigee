    Card

    Status: stable · Since: 0.1.0 · Source: components/ui/card.tsx:47

    Surface container from the Perigee component library.

    Card is a layout primitive only: it owns the border, radius, and background, and has no opinion about content. Compose it with the header / content / footer parts below so every panel in the app has identical spacing.

    Import

    import { Card } from '@/components/ui/card';

    Props

    Card declares no props of its own: every prop is forwarded to the underlying <div> element.

    Inherited attributes

    React.HTMLAttributes<HTMLDivElement> — everything not listed above is spread onto the underlying <div>, including id, style, onClick, aria-*, and data-* attributes.

    Usage

    // Standard composed card
<Card>
  <CardHeader>
    <CardTitle>Vault performance</CardTitle>
    <CardDescription>Since inception, net of fees.</CardDescription>
  </CardHeader>
  <CardContent>{children}</CardContent>
  <CardFooter>
    <Button variant="ghost">View details</Button>
  </CardFooter>
</Card>

    Composition

    The card is a compound component: every part is a plain <div> (or heading / paragraph for the title and description) that renders in order. Only Card itself adds visual chrome, so you can skip any part you do not need:

    • CardHeader — flex column, p-6, tight vertical rhythm.
    • CardTitle — renders an <h3>; keep one per card for a clean outline.
    • CardDescription — muted paragraph that sits under the title.
    • CardContent — body area, p-6 with the top padding removed.
    • CardFooter — horizontal row for actions, p-6 with the top padding removed.

    Accessibility

    • Card accepts focus styling (focus-visible:ring-2) but is not focusable by default: only add tabIndex when the card itself is interactive, and prefer putting a real <button> inside CardFooter.
    • Parts are plain containers, so heading order comes from your page, not from the component — CardTitle renders <h3>; do not skip heading levels.
    • Cards are role="group"-free by default. When a card forms a labelled region, pass role="group" and aria-labelledby pointing at the title.
