    Button

    Actions · Primary and secondary actions, form submits, toolbar controls.

    Page status: stable · Tracks WEB-27 (#113)

    Status: stable · Since: 0.1.0 · Source: components/ui/Button.tsx:70

    Primary action control for the Perigee component library.

    Renders a native <button> and forwards every unhandled prop to it, so type, disabled, aria-*, and event handlers behave exactly as they would on a plain HTML button. Use variant to express emphasis and size for density; keep a single default button per view for a clear primary action.

    Replaces the legacy components/common/Button (CommonButton), whose primary variant maps onto variant="default". See the migration guide for the full mapping.

    Import

    import { Button } from '@/components/ui/Button';

    Props

    PropTypeDefaultRequiredDescription
    variant"default" | "destructive" | "outline" | "secondary" | "ghost" | "link""default"NoVisual treatment. "default" is the cyan brand action; "destructive" is reserved for irreversible actions; "link" renders text-only styling.
    size"default" | "sm" | "lg" | "icon""default"NoControl height and padding. "icon" is a square control for a single glyph.
    asChildbooleanfalseNoAccepted for Radix-style API parity but not implemented yet: the component always renders a <button>. Kept optional so callers migrating from shadcn-based snippets do not fail type checking.

    Inherited attributes

    React.ButtonHTMLAttributes<HTMLButtonElement> — everything not listed above is spread onto the underlying <button>, including id, style, onClick, aria-*, and data-* attributes.

    Usage

    Example 1

    // Primary call to action
<Button onClick={confirmRotation}>Confirm rotation</Button>

    Example 2

    // Lower-emphasis destructive action
<Button variant="destructive" size="sm">Remove vault</Button>

    Accessibility

    • Renders a real <button> whose default type is button, so keyboard activation (Enter / Space) works without extra handlers.
    • Icon-only controls (size="icon") have no text content: always pass an accessible name (aria-label / aria-labelledby) and mark the glyph aria-hidden.
    • Focus is visible via focus-visible:ring-2; the ring must not be removed.
    • disabled uses the native attribute, so the control leaves the tab order and is announced as unavailable. For a loading state that must stay focusable, combine aria-busy with components/ui/Spinner instead.
