    CommonButton

    Legacy · Nothing new — migrate to Button.

    Page status: deprecated

    Status: deprecated · Since: 0.0.1 · Source: components/common/Button/Button.tsx:34

    ⚠️ Deprecated. Superseded by components/ui/Button. The variant names changed (primary → default) and loading folded into the native disabled attribute. See the migration guide.

    Migrate to Button.

    Legacy button from the pre-ui/ component set — prefer Button, which adds size, the full variant set, and native prop forwarding.

    Import

    import { CommonButton } from '@/components/common/Button/Button';

    Props

    PropTypeDefaultRequiredDescription
    variant"primary" | "secondary" | "outline""primary"No—
    loadingbooleanfalseNo—

    Inherited attributes

    React.ButtonHTMLAttributes<HTMLButtonElement> — everything not listed above is spread onto the underlying <button>, including id, style, onClick, aria-*, and data-* attributes.

    Usage

    Example 1

    // Deprecated
<CommonButton variant="primary" loading>Save</CommonButton>

    Example 2

    // Replacement
<Button disabled={loading}>Save</Button>

    Accessibility

    • Adding loading also sets disabled, so the control is removed from the tab order while work is in flight and screen readers announce it as unavailable rather than busy.

    Migration notes

    • Button replaced CommonButton — shipped in v0.1.0.
      • CommonButton set disabled whenever loading was true, so the disabled mapping preserves behaviour exactly.
      • size, ghost, link, and destructive variants exist only on Button.
      • Update the import path as well as the JSX: components/common/Button/Button → components/ui/Button.
